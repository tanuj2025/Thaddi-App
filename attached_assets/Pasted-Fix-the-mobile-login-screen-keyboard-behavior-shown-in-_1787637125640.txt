Fix the **mobile login screen keyboard behavior** shown in the attached screenshots. This is a production React Native / Expo app, so implement a proper native mobile UX solution rather than a temporary layout hack.

### Current Problem

On the Login screen:

1. When the user taps the **Email** field, the keyboard opens and covers part of the login form.
2. When the user moves to the **Password** field, the password input can become hidden behind the keyboard instead of automatically moving into view.
3. The login content does not properly resize/scroll when the Android keyboard appears.
4. The user should never have to manually dismiss the keyboard just to see the field they are currently typing into.
5. The layout should work correctly on real Android production devices with different screen sizes and keyboard heights.

### Expected Production UX

Implement behavior similar to a polished production mobile app:

* When Email is focused → automatically keep the Email field visible above the keyboard.
* When Password is focused → automatically scroll/move the Password field above the keyboard.
* The focused input must NEVER be hidden behind the keyboard.
* The user should be able to scroll the login form while the keyboard is open.
* The Google/Apple buttons, "Forgot password?", Continue button, and Create account link should remain accessible.
* When the keyboard is dismissed, the screen should smoothly return to its normal position.
* Do NOT change the existing visual design, colors, typography, spacing, logo, RTL behavior, or authentication logic.
* Do NOT introduce unnecessary UI changes.

### Recommended Implementation

First inspect the existing login screen component and determine whether it already uses:

* `KeyboardAvoidingView`
* `ScrollView`
* `TextInput`
* `expo-router`
* React Native keyboard events
* any existing keyboard/scroll utilities

Then implement the cleanest solution for the existing architecture.

For Android, make sure the Activity uses the appropriate soft-input behavior, preferably:

`adjustResize`

so the application layout responds correctly when the keyboard opens.

Use a structure similar to:

```tsx
<KeyboardAvoidingView

    keyboardDismissMode="on-drag"
    showsVerticalScrollIndicator={false}

```
